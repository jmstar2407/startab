StarTab v1.4.34 - Control remoto de volumen móvil reforzado

Corrección principal:
- El móvil ya no depende exclusivamente del socket persistente de Firebase RTDB para controlar el volumen del PC.
- Ruta automática: RTDB SDK -> REST autenticado directo -> Firestore fallback.
- Los tres transportes reutilizan el mismo ID de comando para impedir ejecuciones duplicadas si una ruta atrasada vuelve a conectarse.
- El volumen sigue usando interfaz optimista: el valor cambia instantáneamente en pantalla y el último valor del usuario gana.
- Si el socket RTDB del móvil está dormido/suspendido, StarTab usa HTTPS autenticado sin exigir abrir otra sección para “despertar” la conexión.
- Mute/toggle/step reciben el mismo respaldo remoto.
- PCs registrados por versiones anteriores del agente permanecen controlables aunque todavía no expongan todos los metadatos cloud modernos.

Agente Windows:
- Se mantiene v2.9.3; no requiere cambios de C# para esta corrección.
- Recomendado: mantener el agente standalone iniciado con Windows.

Archivos principales modificados:
- windows-system-volume.js
- startab-presence.js
- manifest.json
